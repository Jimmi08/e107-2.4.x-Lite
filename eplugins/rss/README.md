# e107 RSS plugin

e107 RSS Menu plugin commissioned by hpkizi.sk o.z. and jointly open sourced.

This plugin is a customized version of the core RSS Menu plugin, created to meet specific organizational needs and compatibility PHP 7.4. - 8.2.

Recommended for e107 Lite 2.3.4. 

Full credit to the original e107 core development team.
